# Changelog

## v8.5.5

Initial public release candidate.

Includes application management, dashboard/Kanban/calendar, configurable
statuses, exports, master/universal/application CVs, cover-letter snapshots and
templates, A4 cover-page design, PDF generation, personalization and backups.

The release also includes the latest CV/cover-letter preview/PDF alignment
hotfixes and the ReportLab `TA_LEFT` import fix.
