# Contributing

1. Fork the repository and create a topic branch from `main`.
2. Keep changes focused and backward-compatible where practical.
3. Never include personal application data, databases, attachments, signatures,
   photos, credentials or `.env` files.
4. Test the Docker build and affected browser/PDF workflows.
5. Open a pull request explaining the problem, solution and tests.

Project principles: simple Docker deployment, Flask/Jinja with vanilla
JavaScript, preservation of persistent data, and preview/PDF parity for
generated documents.

By contributing, you agree that your contribution may be distributed under
the project's MIT License.
