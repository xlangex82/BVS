# Security Policy

Security fixes target the latest published B-V-S release.

Do not publish vulnerabilities, credentials or personal application data in a
public issue. Prefer GitHub private vulnerability reporting when enabled, or a
private contact channel published by the repository owner.

B-V-S intentionally has no built-in authentication. Internet-facing
deployments should use an authenticated reverse proxy, HTTPS/TLS, appropriate
firewall rules and regular backups.
